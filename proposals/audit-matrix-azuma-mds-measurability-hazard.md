## The hazard, precisely

`MatrixMDS` (the encoding of Tropp's adapted matrix martingale
difference hypothesis, built because the pinned Mathlib has no
filtration API) had three fields:

- `adapted : ∀ k, StronglyMeasurable[mdsFiltration X (k+1)] (X k)`,
  where `mdsFiltration X k` is the comap of the product σ-algebra
  along `ω ↦ (X 0 ω, …, X (k−1) ω)`;
- `cond_mean_zero : ∀ k S, MeasurableSet[mdsFiltration X k] S →
  ∫ ω in S, X k ω ∂μ = 0`;
- `norm_bound : ∀ k ω, ‖X k ω‖ ≤ R`.

Two independent defects, one consequence:

1. **The `adapted` field is content-free.** `mdsFiltration X (k+1)` is
   generated by `X 0, …, X k` themselves, so `X k` is measurable
   against it *definitionally* — proved for every `X` as
   `measurable_mdsFiltration_QA` (the comap-cylinder route). The field
   constrained nothing; Tropp's adaptedness hypothesis was not actually
   encoded.
2. **Nothing forces ambient strong measurability.** With `X k` not
   `StronglyMeasurable[mΩ]`, the `cond_mean_zero` integrals are
   `integral_non_aestronglyMeasurable` junk zeros (the §4 mechanism on
   the matrix side): every `∫ ω in S, X k ω ∂μ = 0` clause holds
   *vacuously*.
3. **Consequence:** the martingale hypothesis is satisfiable by a
   bounded non-measurable drift, and the axiom's conclusion fails on
   it — materially false in hypothesis form, exactly the Errata
   class of an encoding that silently dropped a hypothesis the cited
   source carries implicitly (Tropp 2012 works with adapted processes
   on a filtered probability space; measurability w.r.t. the ambient
   σ-algebra is part of that setup).

**Technique findings** (for future Step-0s on this shelf):

- A docstring cannot precede `omit … in` — the parser expects the
  declaration immediately after the docstring; the `omit` line goes
  first, the docstring between it and the theorem. (The spike, which
  had no docstring on that lemma, hid this; the shelf copy with one
  failed to parse — the two shelf/spike divergences were exactly of
  this transcription kind.)
- `simp` can close `1 ≤ ‖(1 : Matrix (Fin 1) (Fin 1) ℝ)‖` outright on
  `Fin 1`; to keep the eigenvalue interface load-bearing
  (`l2OpNorm_le_of_abs_evals_le`/`abs_evals_le_l2OpNorm`/`evals_one`)
  the final step must be `rw [evals_one, abs_one] at h; exact h` — any
  `simpa`-flavored closer triggers the "try simp" linter note by
  out-clevering the content.
- The junk-integral mechanism needs *both* values of the non-measurable
  function to carry positive mass for the `¬ AEStronglyMeasurable`
  argument (`stronglyMeasurable_bot_iff` + `ae_eq_mk` +
  `ae_imp_of_ae_restrict`); a function that is a.e. constant is
