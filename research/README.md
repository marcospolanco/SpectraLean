# Research Materials

This directory contains material that informs Scaffold's research program but is not part of the Lean library or its governing documentation.

## Layout

- [`papers/`](papers/) contains reference papers and other research artifacts kept in the repository.
- [`archive/`](archive/) preserves raw transcripts, historical reports, superseded policies, and earlier specifications for provenance.

Current project claims and policy live under [`docs/`](../docs/). Files in this directory may be exploratory, historical, externally authored, or otherwise outside the repository's verified source surface.
