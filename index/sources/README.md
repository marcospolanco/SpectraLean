# Source Index

This directory contains detailed mappings from primary sources to Lean axioms.

## Purpose

Each file in this directory documents:

1. Full bibliographic citation for a source (textbook, paper, monograph)
2. Scope of results used from that source
3. Table mapping theorem numbers to Lean axiom identifiers
4. Notes on variations or simplifications in the formal statements

## Contributing

When adding a new axiom:

1. Create or update the corresponding source file
2. Add an entry to the theorem-to-axiom mapping table
3. Include precise theorem numbers and page numbers
4. Note any significant variations from the source statement
