# Topic Maps

This directory contains mappings from mathematical topics to Lean modules and axioms.

## Purpose

Each file in this directory:

1. Groups axioms by mathematical topic
2. Provides a high-level overview of available results
3. Links to detailed source information
4. Includes usage patterns and application notes

## Available Maps

- [Spectral Graph Theory](spectral_graph.md) - Laplacians, spectra, Cheeger, and event dynamics (the SGT center)
- [Probability Concentration](probability_concentration.md) - Scalar concentration inequalities
- [Random Matrix Theory](random_matrix.md) - Matrix concentration inequalities
- [Perturbation Theory](perturbation.md) - Spectral stability and perturbation bounds

## Contributing

When adding new axioms:

1. Update the appropriate topic map with the new axiom
2. Include a brief description and source reference
3. Add usage patterns if applicable
4. Create a new topic map file if starting a new area
